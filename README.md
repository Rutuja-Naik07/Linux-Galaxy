# Linux Notes: Beginner to Advanced

A single-file, interactive set of Linux notes. No build step or dependencies.

## View it

Open `linux-notes.html` in any browser.

To host it free on GitHub Pages:

1. Rename `linux-notes.html` to `index.html`.
2. Push to a GitHub repo.
3. In the repo, go to Settings, then Pages, and choose the main branch.

## Contents

- **Beginner:** filesystem tree, essential commands, permissions calculator
- **Intermediate:** pipes, grep/find/sed/awk, processes, users, packages, scripting
- **Advanced:** boot sequence, systemd, networking and SSH, cron, troubleshooting, containers, security
